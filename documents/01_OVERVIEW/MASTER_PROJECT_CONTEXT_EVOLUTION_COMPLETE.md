## 🎯 **MASTER PROJECT UNDERSTANDING**

### **What This Is (Current Reality)**
Mini-Agent is a **production-grade AI agent platform** that evolved from a teaching demonstration into a comprehensive enterprise tool with:

#### **🏗️ Core Architecture (Verified)**
- **Modular Design**: 400+ files across 15+ specialized modules
- **Tool Ecosystem**: 50+ specialized tools across 8 categories

- **Multi-Provider LLM**: Support for MiniMax-M2, OpenAI, Z.AI

- **CLI Interface**: `mini-agent` interactive session
- **ACP Integration**: Editor plugin support (`mini-agent-acp`)
- **Extensible Framework**: Easy addition of tools and skills

## 🔧 **TECHNICAL ARCHITECTURE DECISIONS**

### **Design Philosophy**
- **Modularity First**: Every component independently testable and replaceable
- **Extension by Design**: Easy addition of tools, skills, and integrations
- **Production Ready**: Error handling, retry logic, monitoring from day one
- **Security Conscious**: Multi-layer protection for cost and data safety
- **Developer Friendly**: Clear APIs, comprehensive documentation, debugging support

### **Key Architectural Choices**

#### **1. Tool-Based Architecture**
**Decision**:抽象 tool interface with implementations  
**Rationale**: Enables easy extension while maintaining consistency  
**Impact**: 50+ tools available, each serving specific domain expertise

#### **2. Skills Framework**
**Decision**: Progressive disclosure skill loading  
**Rationale**: Domain expertise without overwhelming initial complexity  
**Impact**: 15+ specialized capabilities accessible on demand

#### **3. Multi-Provider LLM**
**Decision**: Provider-agnostic LLM client wrapper  
**Rationale**: Avoid vendor lock-in, enable best-of-breed selection  
**Impact**: Support for MiniMax-M2, OpenAI, Z.AI with consistent interface

#### **4. Credit Protection**
**Decision**: Multi-layer cost safety system  
**Rationale**: Prevent unexpected expenses in production use  
**Impact**: Guaranteed cost control with zero risk of overrun

#### **5. Configuration-Driven Behavior**
**Decision**: YAML configuration with environment overrides  
**Rationale**: Flexible deployment across environments  
**Impact**: Single codebase adapts to development, staging, production

## 🎯 **DEPLOYMENT ARCHITECTURE**

### **Development Environment**
```bash
# Local development
git clone <repo>
cd mini-agent
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
mini-agent  # Start interactive session
```

### **Production Deployment**
```yaml
# docker-compose.prod.yml
services:
  mini-agent:
    build: .
    environment:
      - MINIMAX_API_KEY=${MINIMAX_API_KEY}
      - ZAI_API_KEY=${ZAI_API_KEY}
    volumes:
      - ./config:/app/config:ro
      - ./workspace:/app/workspace
    restart: unless-stopped
```

### **Cloud Deployment**
```bash
# AWS/GCP/Azure containerized deployment
docker build -t mini-agent:latest .
docker run -d \
  --env-file .env \
  -v $(pwd)/config:/app/config:ro \
  -p 8080:8080 \
  mini-agent:latest
```
